# Video Production Skill

An agent skill for planning and producing narrated product videos, with reusable scripts, templates, and visual design resources.

The portrait workflow uses a content-first scene design contract: agents decide the viewer task, dominant information, image role, attention order, and sequence rhythm before choosing geometry. New XYZCHEM projects default to a low-prescription `adaptive` scene seed; the six older named scene templates remain available as compatibility starters.

This package was prepared from the `video-production-20260918-132324` backup. Backup metadata, production records, and temporary product data sheets were excluded. Third-party materials retain their own license and attribution files; this repository has no blanket license.

## Contents

- `references/composition-system.md` — content-first composition and whole-video rhythm
- `scripts/scene_design.py` — scene design contract and sequence checks
- `templates/video/adaptive.html` — low-prescription portrait scene seed
- `scripts/`, `templates/`, `assets/`, `references/` — reusable implementation resources
